화면에서 호출하지 않는 엔드포인트

`GET /categories` 하나. 프로토타입은 설비 목록을 `constants.js` 상수로 들고 있다. 실제 구현에서는 U-02·U-07 의 설비 선택지와 A-02·A-03 의 설비 필터를 이 엔드포인트로 채운다.

API 를 부르지 않는 조작

W-02 · A-02 의 정렬 선택, A-06 의 층 순서 토글, W-05 의 탭 전환은 표시 계층에서만 동작한다. 서버 정렬과 기본 질의를 바꾸지 않겠다는 결정의 결과다.

한 엔드포인트가 여러 화면

`GET /complaints` 가 미배정 목록 · 내 작업 · 전체 민원 · 지연 민원 네 화면을 담당한다. 화면별로 질의 조건만 다르다 (15.2).

상세 조회의 짝

`GET /complaints/{id}` 와 `/related` 는 W-03 · A-03 · A-05 에서 항상 함께 호출된다 — 중복 판단에 같은 위치 민원이 필요하기 때문이다.
